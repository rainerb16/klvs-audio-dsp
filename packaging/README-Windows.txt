Rainr Audio {PLUGIN} {VERSION} for Windows (test build)

1. Copy the {PLUGIN}.vst3 folder to:  C:\Program Files\Common Files\VST3
   (Windows asks for administrator permission; that's normal for this folder.)
   Tip: if you haven't yet, right-click the downloaded zip > Properties > tick "Unblock"
   before extracting.

2. In Ableton Live: Options > Preferences > Plug-Ins > turn on
   "Use VST3 Plug-in System Folders" > Rescan.
   Find it under Plug-Ins > Rainr Audio > {PLUGIN}.

Updating: quit Live and delete the old {PLUGIN}.vst3 folder first, then copy the new one.

Full instructions and troubleshooting:
https://github.com/rainerb16/rainr-audio-dsp/blob/main/docs/INSTALL.md
