# WRM1 DSP lab

Offline Python model of WRM1. `wrm1.py` is the reference the C++ plugin must match.

## Setup (once, no Homebrew)
    cd ~/projects/rainr-audio/dsp-lab
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

Run `source .venv/bin/activate` again in each new terminal.

## Use
    python render.py ~/Music/mymix.wav           # A/B renders -> renders/mymix/
    python render.py ~/Music/mymix.wav --blind   # + shuffled blind set and key
    python measure.py ~/Music/mymix.wav          # harmonics, auto gain, low protect, aliasing
    python calibrate.py mix1.wav mix2.wav ...    # rebuild Auto Gain table from real mixes

Files: `wrm1.py` (DSP + tuning constants), `analysis.py` (meters, test signals),
`autogain_table.json` (generated by calibrate.py; part of the spec).
